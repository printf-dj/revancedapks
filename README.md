## ⚙️ Before You Start

### MicroG / Google Services

For supported non-root builds of YouTube, YouTube Music, and Google Photos, you may need a compatible Google services implementation.

- **Morphe-compatible MicroG:** [MorpheApp/MicroG-RE](https://morphe.software/microg)
- **Morphe project:** [morphe.software](https://morphe.software)

Follow the relevant installation instructions for your chosen APK. Requirements may differ between apps and builds.

---

## 📲 Installation Guide

1. **Choose your app:** Open the [latest releases](https://github.com/printf-dj/revancedapks/releases/latest).
2. **Download the APK:** Select the appropriate build from the release assets.
3. **Install required components:** If the app requires MicroG or another compatible component, install it according to its official instructions.
4. **Allow installation:** If prompted, enable *Install unknown apps* for the browser or file manager you are using.
5. **Install the APK:** Open the downloaded file and follow Android's installation prompts.
6. **Enjoy:** Launch the app and configure its settings as needed.

**Note:** Android may prevent installation if the APK conflicts with an existing app's signing certificate or package. Back up important data before replacing an existing installation.
